# BIORUST
Biorust is a Mindustry mod designed to achieve 4 things despite using the very limited HJSON coding system:
1. Give a 96-sector campaign across 3 planets.
2. Introduce new mechanics, or at least more interesting ways to do stuff.
3. Be realistic, but limit it so it doesn't make this a horrible mod.
4. Introduce lore which confirms some theories.

Uh yeah and we're also a couple crazy people who do crazy things.

Are you done with **BioRust**? *You physically cannot be done with BioRust yet.*
Well, try the continuation, **Project: Extraction**!
It continues the lore a small bit, but focuses on what happened to Quantum during and after the events of **BioRust**.
